# nano-avr

PanelsDCC node sketch. The folder and the `.ino` are both `nano-avr`.

Boot banner: `PanelsDCC Node {prefix} nano-avr READY` at 9600 8N1.

This image is compiled per person by panelsDCC-Nodes. It is not in the generic catalog. Connect flashes `nano-avr.hex`, sends `PREFIX`, then reads the pin layout with `CFG?`.
